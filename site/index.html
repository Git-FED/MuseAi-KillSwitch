§ 02

Defense in depth

When one control fails, another still narrows the blast radius. Every layer is visible, testable, and independently useful.

01 / Panic plane

Global STOP or KILL, confirmed by an operator. Supersedes every agent-scoped state.

02 / Budget tripwire

At 5% notify. At 7.5% pause non-essential work. At 10% pause all and ask for escalation.

03 / Execution fence

Drain queues to an auditable directory and stop optional timers. Never silently delete work.

§ 03

Guard contract

Every agent adds one line at the top of its loop. The check must not be hidden behind a network-only service or an in-process boolean.

run_loop.py / fail-closed hook
from src.guard import KilledError, check_kill

def run_loop():
    while True:
        try:
            check_kill("poster")
        except KilledError:
            checkpoint_read_only_work()
            return
        perform_one_small_action()

Database errors propagate. That is intentional: if the agent cannot prove it is allowed to continue, it stops.

NON-NEGOTIABLE: kill state lives outside the agent. If the agent can edit the flag that stops it, the flag is not a kill switch.
§ 04

Incident drill

Build confidence before production by rehearsing the exact operator path in a disposable workspace.

  1. Run ./bin/kill.sh status.
  2. Pause one non-essential agent and verify its loop exits.
  3. Revive it and verify the transition is logged.
  4. Run a global kill in a disposable environment.
  5. Inspect audit.log; redact secrets before sharing the receipt.
break-glass / local terminal
$ ./bin/kill.sh status
CONTROL PLANE :: CLEAR — no active kills
$ ./bin/kill.sh pause poster "operator drill"
activated kill #1 :: agent:poster :: PAUSE
$ ./bin/kill.sh revive poster
revoked 1 active kill(s) :: audit receipt written
$
operator sequence
./bin/kill.sh pause poster "operator drill"
./bin/kill.sh status
./bin/kill.sh revive poster
./bin/kill.sh status
§ 05

Deployment matrix

One site, five targets. The companion Web2App blueprint covers Android, iOS, Windows, Linux, and PWA. macOS is intentionally out of scope: no bundle, no workflow, no release target.

Mobile // Android

Kotlin WebView with local assets, allowlisted external schemes, and APK/AAB output.

Mobile // iOS

Swift/WKWebView simulator artifact with no macOS application bundle.

Desktop // Windows

Tauri 2 + WebView2, current-user NSIS/MSIX packaging.

Desktop // Linux

Tauri 2 + WebKitGTK, AppImage and deb targets.

Web // PWA

Relative manifest, versioned service worker, and offline shell caching.

Excluded // macOS

No .dmg, .app, .icns, Apple target, or macOS release workflow.

§ 06

Asset integrity

Every HTML repository gets a recognizable browser tab, mobile home-screen icon, and PWA install surface. The source of truth is favicon.svg; the standalone page also carries an inline fallback for direct file opening.

PRE-SHIP CHECK: no HTML repository is complete until its identity survives the browser tab, a pinned shortcut, and a disconnected launch.
