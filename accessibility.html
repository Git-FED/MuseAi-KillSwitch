A high-contrast, keyboard-first interface

The command center is designed with visible focus states, semantic landmarks, responsive layouts, readable contrast, copy controls, and a reduced-motion mode.

Known limitations

  • Third-party payment widgets may not expose the same accessibility behavior as the surrounding page.
  • Animated scanlines and telemetry are decorative and are disabled or minimized when reduced motion is requested.
  • Report an issue using the support email in the footer.

Keyboard use

Use Tab to move through navigation, support links, forms, and copy controls. Use Escape or browser navigation to leave external provider pages.
